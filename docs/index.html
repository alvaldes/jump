JUMP
Source on GitHub

Click anything on your Mac without touching the mouse.

Press a shortcut and every button, link and field in the window gets a short label. Type the label to click it.

Download for Mac
brew install --cask alvaldes/tap/jump

Version 1.1.0 for macOS 26 and later. Free and open source.

Three modes, one shortcut each.

⌘⇧Space

Hints

Labels every clickable element of the focused window. Type a label to click it. Hold ⇧ to right-click, ⌘ to double-click or ⌥ to only move the pointer, or pick other modifiers in Settings.

⌘⇧J

Scroll

Scrolls the window with h j k l, half a page with d u, to either end with gg G. Tab moves to the next scrollable area.

⌘⇧F

Text search

Finds any text visible in the window, ignoring case and accents. Tab moves between matches and Return puts the cursor there.

Made to stay out of your way.

Gone when you move on

Switch apps with the mouse, ⌘-Tab or a window manager like AeroSpace and the labels disappear on their own.

Reads text you can't select

For terminals, PDFs and images, text search can recognize what is on screen. It's off until you turn it on, and nothing leaves your Mac.

Yours to adjust

Change the shortcuts or turn them off in the apps you choose, the modifier for each click action, the letters labels use, five label themes, sizes from 7 to 20 pt, Liquid Glass and scroll speed.

Open source

GPL-3.0, built on ideas and code from Vimac. Read the code, report issues or send changes on GitHub.

Set it up the way you work.

Install in a few minutes.

  1. Download JUMP.dmg, open it and drag JUMP to Applications, or use Homebrew:

    brew install --cask alvaldes/tap/jump

  2. Open JUMP from Applications. macOS stops it the first time: choose Done, then click Open Anyway in System Settings, Privacy & Security.

    JUMP isn't notarized by Apple yet, so you confirm it once. Step-by-step guide with screenshots

  3. Allow JUMP in Accessibility when it asks.

    That's how JUMP finds and clicks elements in other apps.

  4. Press ⌘⇧Space in any window.
